# FitBodyRD Flutter App

A comprehensive fitness and nutrition tracking application built with Flutter and powered by Serverpod backend.

## 📱 Overview

FitBodyRD is a mobile application designed to help users track their fitness journey, manage nutrition plans, and achieve their body goals. The app provides personalized workout routines, meal planning, and progress tracking features.

## ✨ Features

- **User Authentication**
  - Email/Password authentication
  - Google Sign-In integration
  - Secure token-based session management

- **User Onboarding**
  - Multi-step onboarding flow
  - Personalized profile setup (body stats, goals, activity level)
  - Dietary restrictions and exercise difficulty preferences

- **Profile Management**
  - View and edit user information
  - Track fitness metrics
  - App version display
  - Secure logout functionality

- **Nutrition Planning**
  - Personalized meal plans
  - Food tracking and logging
  - Nutritional information

- **Workout Management**
  - Custom exercise routines
  - Workout tracking
  - Progress monitoring

## 🏗️ Architecture

The app follows **Clean Architecture** principles with a feature-based structure:

```
lib/
├── features/           # Feature modules
│   ├── auth/          # Authentication & authorization
│   ├── onboarding/    # User onboarding flow
│   ├── profile/       # User profile management
│   └── splash/        # Splash screen & initial routing
├── src/
│   ├── app/           # App configuration & initialization
│   └── core/          # Shared utilities & resources
│       ├── env/       # Environment configuration
│       ├── extensions/# Dart extensions
│       ├── injections/# Dependency injection (GetIt)
│       ├── routing/   # Navigation (GoRouter)
│       ├── services/  # Core services
│       ├── style/     # Theme & design system
│       └── utils/     # Helper utilities
└── main.dart          # App entry point
```

### Key Technologies

- **State Management**: BLoC (flutter_bloc)
- **Dependency Injection**: GetIt
- **Routing**: GoRouter
- **Backend Client**: Serverpod
- **Secure Storage**: flutter_secure_storage
- **UI Utilities**: flutter_screenutil, Google Fonts

## 🚀 Getting Started

### Prerequisites

- Flutter SDK `>=3.24.0`
- Dart SDK `>=3.5.0 <4.0.0`
- Running FitBodyRD backend server
- iOS/Android development environment setup

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd fitbodyrd/fitbodyrd_flutter
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Configure environment variables**
   
   Copy the example environment file:
   ```bash
   cp .env.example .env
   ```
   
   Edit `.env` with your configuration:
   ```env
   ENVIRONMENT=development
   SERVERPOD_URL=http://localhost:8080
   GOOGLE_REDIRECT_URL=<your-google-redirect-url>
   GOOGLE_SERVER_CLIENT_ID=<your-server-client-id>
   GOOGLE_CLIENT_ID_ANDROID=<your-android-client-id>
   GOOGLE_CLIENT_ID_IOS=<your-ios-client-id>
   ```

4. **Generate code**
   ```bash
   # Generate environment configuration
   dart run build_runner build --delete-conflicting-outputs
   
   # Generate assets (if needed)
   flutter pub run flutter_gen_runner
   ```

5. **Run the app**
   
   Make sure the backend server is running first, then:
   ```bash
   flutter run
   ```

### Development Scripts

- **Reload environment variables**
  ```bash
  ./reload_env.sh
  ```

- **Generate code (watch mode)**
  ```bash
  dart run build_runner watch --delete-conflicting-outputs
  ```

## 🔧 Configuration

### Google Sign-In Setup

1. Create a project in [Google Cloud Console](https://console.cloud.google.com)
2. Enable Google Sign-In API
3. Configure OAuth consent screen
4. Create OAuth 2.0 credentials for:
   - Web application (for server)
   - Android application
   - iOS application
5. Add the client IDs to your `.env` file

### Serverpod Client

The app uses the `fitbodyrd_client` package (located in `../fitbodyrd_client`) to communicate with the backend. This client is automatically generated by Serverpod and provides type-safe API calls.
